# Legal Notes

Hogwarts Indonesia adalah proyek ensiklopedis/fan-made independen berbahasa Indonesia. Proyek ini tidak boleh menyiratkan afiliasi resmi dengan Warner Bros. Discovery, J.K. Rowling, Wizarding World, Universal, atau pemegang hak terkait.

## Konten teks

- Jangan menyalin novel, artikel resmi, atau buku referensi berhak cipta secara verbatim dalam jumlah substansial.
- Fakta dapat diringkas secara ensiklopedis dengan narasi original dan sumber yang dapat ditelusuri.
- Kutipan harus sangat terbatas dan hanya ketika benar-benar diperlukan; paraphrase diprioritaskan.
- Konten interpretatif harus diberi label sebagai interpretasi editorial.
- Materi imajinatif non-canon harus dipisahkan dan dilabeli jelas.

## Visual

Dilarang memasukkan screenshot film, frame Warner Bros., poster resmi, official key art, logo film, soundtrack resmi, atau likeness aktor tanpa dasar hak penggunaan yang jelas. Identitas visual proyek harus original.

## Aset internet

Ketersediaan file di web tidak berarti izin untuk menyalin. Setiap aset harus melewati audit lisensi dan attribution di `assets-manifest.json`. Website resmi dapat menjadi sumber riset, tetapi file gambarnya tidak otomatis memiliki lisensi redistribusi.

## Komersialisasi

Nama, karakter, lokasi, istilah, dan elemen lain dari Wizarding World dapat dilindungi oleh hak cipta dan/atau merek. Sebelum penggunaan komersial, monetisasi, distribusi berbayar, sponsorship, atau pemasaran produk, lakukan tinjauan hukum profesional dan dapatkan lisensi/izin yang relevan. Dokumen ini bukan nasihat hukum.
